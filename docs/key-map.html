Where each key sits on the device and what it does by default. To change a key, right-click the tray icon, choose Edit config, then Reload config.

Dial modes (press the dial to cycle)

Using the dial

  • Model: turn to pick a model; it switches when you stop. If Claude asks “Switch model?”, press the dial to confirm, or K3 (Esc) to cancel.
  • Effort: turning moves Claude’s effort slider, from Low to Ultracode.
